# AWS Architecture Icons

Official AWS Architecture Icons (48px service icons, 64×64 viewBox), used per
AWS's architecture-icon usage terms: https://aws.amazon.com/architecture/icons/

- `AmazonS3.svg`, `AWSCostExplorer.svg`, `AWSXRay.svg`, `AWSIAM.svg` — extracted
  from the official Icon-package (release 07312026), downloaded 2026-10-01.
- The remaining icons were vendored from the AgentCoreKiosk project's copy of
  the same official set.
- `User.svg` / `Document.svg` are the general resource icons from the package.
